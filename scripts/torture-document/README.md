# Teretisma specimen

This directory contains a new, publisher-neutral font specimen. It has no publisher logos, book imprints, house-style layout, ISBN examples, or publisher-specific notices.

Run `make -C scripts render-pdf` after building the fonts. The PDF is written to `scripts/pdf-output/document.pdf` and exercises the installed Teretisma families, all four text styles, Latin/Greek/Cyrillic, IPA, math symbols, and the five icon glyphs.

The original publication examples and branded assets are retained only in Git history. Font heritage and required ownership notices are documented at the repository root.
