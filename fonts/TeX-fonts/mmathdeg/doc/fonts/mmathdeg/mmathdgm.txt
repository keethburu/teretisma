The MinionMath fonts are re-installed according to the requirements for
Teretisma. For formulas, Teretisma wants as many as possible characters
from the De-Gryuter-Serif and Teretisma-Sans fonts, comprising Greek
variable symbols.

For the rest, Teretisma wants the MinionMath fonts to be used.
For MinionMath fonts, see www.typoma.de.

For the following, it is presupposed that the De-Gryuter-Serif,
the Teretisma-Sans fonts, and the minionmath package are installed.

The idea is to reconstruct the minionmath's OML- and MC-encoded fonts,
but with all the required substitutions from Teretisma-Serif and
Teretisma-Sans.

MinionMath provides optical sizes, but Teretisma(Serif|Sans) does not.
So, the new fonts lack in this feature partially.

For installation details see mmathdeg.sh and
mmathdeg-drv.tex.

Access is via mmathdeg.sty.
